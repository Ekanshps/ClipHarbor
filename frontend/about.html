Built by a developer who was tired of ad-filled downloaders

Hi, I am EP Singh, a developer who builds small, fast web tools. See my other projects: PixelPress and ReelDownloader.

Why I made ClipHarbor

Most downloader sites are slow, flooded with pop ups and push you to install something. I wanted a clean tool that does one job: paste a link, pick a quality, download. No login, no watermark, no limits.

How it works

The frontend is plain HTML, CSS and JavaScript. The backend is a small Flask API using yt-dlp and FFmpeg. Files are deleted from the server right after your download finishes.
